3. Vulkan clear demo (ENG-03)
   Required changes discovered on real dependencies:
   a) vcpkg.json: sdl3 needed the non-default 'vulkan' feature
      ({"name":"sdl3","features":["vulkan"]}); without it SDL rejects
      SDL_WINDOW_VULKAN ('Vulkan support is either not configured...').
   b) -DMINGW_BUILD=TRUE is required with a non-MinGW generator name:
      Diligent only sets MINGW_BUILD for generators matching 'MinGW',
      and otherwise compiles DXCompiler.cpp which needs atlbase.h
      (unavailable on MinGW). This matches upstream's MinGW intent and
      disables the DXC shader path only.
   c) GCC 16/libstdc++ no longer provides uint32_t transitively; the
      pinned glslang SpvBuilder.h lacked <cstdint>. The root
      CMakeLists.txt now adds the missing include to the fetched source
      at configure time.

   pokox_vulkan_clear.exe built and linked against real SDL3 3.4.20 and
   static Diligent-GraphicsEngineVk-static.

   First run (no --adapter): Diligent auto-selection chose
   'Microsoft Direct3D12 (Microsoft Basic Render Driver)' (WARP). A
   captured Diligent error/fatal ('Debug assertion failed in
   FindQueueFamily ... minImageTransferGranularity') failed the demo

   ClearConfig gained adapter_id and the demo gained --adapter N
