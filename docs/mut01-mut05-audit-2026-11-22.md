# MUT-01–05 audit — 2026-11-22

## Scope and method

Reviewed the UTF-8 lexer and Unicode tables, arithmetic AST parser and checked evaluator, SDL/ImGui console input path, and print bridge/bounded log, their current contracts, and automated tests. Re-ran the strict warnings-as-errors suite, sanitizer suite, exhaustive i8 arithmetic test and, where noted in MUT-06 progress, software-Vulkan integration. This is a targeted implementation audit, not an independent formal verification or certification for every platform. See earlier MUT-01–03 audits and MUT-04/05 reports for the findings and fixes made before this review.

## Findings

| Area | Result / remaining issue |
| --- | --- |
| MUT-01 | UTF-8 and numeric token contracts, pinned Unicode generation, resource source cap, malformed inputs and lexer golden tests are covered. Identifier/version rules remain initial choices, not proof of full language compatibility. |
| MUT-02 | Owned arithmetic AST, precedence, locations, malformed input and deep expressions are covered by unit, golden and independent reference tests. This is still an arithmetic parser, not a full-language grammar. |
| MUT-03 | Checked integer arithmetic, binding validation, float environment guards and exceptional paths have regression coverage; i8 operations were exhaustively retested. Floating results are not proven cross-platform deterministic; 10k-tick cross-platform replay and hosted/target builds remain open. |
| MUT-04 | Input, rendering and F1 behavior are exercised using X11 synthetic events and software Vulkan. The input buffer is bounded. This does not establish behavior for IME, physical GPUs, Windows, Android, or every display scale. |
| MUT-05 fixed | Display ambiguity: an actual newline and the literal backslash-plus-`n` were previously both rendered as `\n`. The log now also escapes backslashes; a regression compares the two. Raw host callback bytes and FIFO limits are unchanged. |
| MUT-05 open | Escaping covers ASCII controls and backslashes, **not** Unicode bidi/format controls or all possible spoofing. Do not treat the log as a security-grade sanitizer. `print` is a narrow top-level bridge, not a VM hostcall or general callable function; string interpolation is rejected. |

The related AST dump uses hex escapes for backslash and controls and did not show this ambiguity. The display-log root cause was checked in the Mute and demo source paths; this is a scoped search, not proof there are no variants elsewhere in the repository.

No new directories were introduced: public Mute interfaces, implementations, unit tests and graphics integration tests remain in their existing respective folders. Open gates remain open, including hosted CI, Windows/MSVC and Android tests, production sandbox limits, and deterministic replay. A passing local suite does not mean the entire project has no issues.

## Local verification and observation

The final strict Linux/GCC suite passed 56/56, the ASan/UBSan suite passed 56/56, and the exhaustive signed/unsigned 8-bit binary arithmetic check passed 655,360 cases. The final software-Vulkan suite passed 79/79 on rerun. One preceding concurrent run failed the existing cube-golden X11 screenshot read with `BadMatch (X_GetImage)`; an earlier graphics run and the isolated rerun passed. The cause was not established, so intermittent capture/test flakiness remains open rather than being reported as fixed. The graph refresh reported 155 files without supported extraction; its coverage is partial.
